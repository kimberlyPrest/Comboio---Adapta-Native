# Decisões incorporadas ao escopo — 29/09/2026

O cliente pediu um sistema interno que possa começar com cadastro e agendamento de previsões, além de uma visão simplificada para o motorista já registrado solicitar sua própria chegada. Pediu campos/cadastros próprios para empresa, motorista e equipe interna. O reconhecimento facial deve constar do projeto, mas não da primeira fase; a integração futura pode usar API da AWS. A stack definida para o sistema é Skip (plataforma web da Adapta) com banco/autenticação no Supabase.

Essas decisões estão incorporadas ao [escopo definitivo](../01_projeto/02-Escopo-Definitivo.md) e às quatro SPECs da fase 1. Este registro documenta a conversa de trabalho; não afirma que a Comboio tenha aprovado regras operacionais ainda marcadas como pendentes.
