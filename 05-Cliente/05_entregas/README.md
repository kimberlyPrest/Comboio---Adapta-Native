# Entregas e evidências

Esta pasta receberá **somente** entregas aprovadas e evidências sem dados pessoais reais. Ainda não há sistema implementado, link público nem aceite de produção.

Para cada task F1-001 a F1-024, registrar: data, responsável, versão do Skip, migração/função Supabase correspondente, cenário testado, resultado, evidência e pendência. Antes do piloto, anexar matriz de permissões/RLS, prova de restauração do backup, teste dos fluxos principais e aceite da Comboio. Nenhuma captura deve expor CPF, telefone, chaves ou token.
