# Entregas e evidências

Esta pasta receberá **somente** entregas aprovadas e evidências sem dados pessoais reais. A fase 1 concluída está arquivada em [fase-1/](fase-1/fase.md), com SPECs, tasks e matriz.

Para cada task, registrar: data, responsável, versão do Skip, migração/função Supabase correspondente, cenário testado, resultado, evidência e pendência. Antes do piloto, anexar matriz de permissões/RLS, prova de restauração do backup, teste dos fluxos principais e aceite da Comboio. Nenhuma captura deve expor CPF, telefone, chaves ou token.
